# История изменений

## 1.2.0 — 2026-10-10

- Вывод HTTP-кода и действия Wordfence, IP, URL-пути последнего обращения по каждому AI-краулеру.
- Состояние совпадения IP с официальным CIDR-списком, отдельно от User-Agent; последний подтверждённый ответ 2xx.
- Подробности по пяти последним событиям каждой группы User-Agent.
- Сводка запросов за 7 и 30 дней: всего, успешные 2xx, ограничения 401/403/429 и действия Wordfence, **только в доступной выборке** последних 5000 записей.
- Добавлен официальный список IP Anthropic (`claude.com/crawling/bots.json`) для Claude.
- Защита данных: URL отображаются без параметров и фрагментов; старые URL из версии 1.1.0 очищаются при первом пересчёте.
- Исторические даты и настройки виртуального robots.txt сохранены; сканирование не изменяет WAF или таблицы Wordfence.

## 1.1.0 — 2026-10-10

- Просмотр дат визитов AI-ботов из Wordfence Live Traffic; IP-проверка для OpenAI, Google, Perplexity.
- Рекомендация включить All Traffic вручную с предупреждением о нагрузке.
- Запоминание последних найденных дат после очистки журнала Wordfence.

## 1.0.0 — 2026-10-09

- Диагностика Wordfence и доступности публичных адресов.
- Безопасное управление виртуальным robots.txt, ручная проверка IP.
