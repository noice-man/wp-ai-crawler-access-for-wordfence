Безопасная диагностика AI-краулеров и настройка виртуального robots.txt без исключений из WAF.

== Description ==

Лёгкий аддон для WordPress. Не меняет код и конфигурацию Wordfence и не отключает защиту.

* Показывает состояние Wordfence и наличие физического robots.txt.
* Проверяет HTTP-доступность главной, robots.txt и llms.txt от IP вашего сервера.
* По явному действию администратора добавляет разрешённые AI User-agent группы в виртуальный WordPress robots.txt, только если это не обходит найденные ограничения.
* Уважает уже заданные отдельные User-agent группы, защищает /wp-admin/ и /wp-login.php.
* Проверяет IP по официальным спискам OpenAI, Google, Perplexity и Anthropic (Claude).
* Показывает последний HTTP-статус, IP, путь URL (без query-параметров) и статус совпадения с официальным IP-списком.
* Сводка за 7 и 30 дней: запросы, HTTP 2xx и ограничения в пределах ограниченной выборки Live Traffic.
* Показывает последний успешный визит с IP, совпадающим с опубликованным диапазоном.
* Под каждой строкой бота отображает 5 последних запросов, их статус, IP, URL и результат сверки.
* Предлагает включить All Traffic вручную для наблюдения за успешными обходами; никогда не переключает настройку автоматически.
* Подсказывает безопасные штатные настройки Wordfence.

== Installation ==

1. WordPress → Плагины → Добавить новый → Загрузить плагин.
2. Установите ZIP и активируйте.
3. Откройте слева «AI Crawlers».
4. Выполните «Проверить сайт», изучите robots.txt.
5. При желании отметьте AI-ботов и нажмите «Сохранить правила robots.txt».
6. Откройте публичный /robots.txt и сверьте результат.
7. Для статистики успешных визитов включите All Traffic в интерфейсе Wordfence, учитывая нагрузку; обновите отчёт в AI Crawlers.

== Important limitations ==

- НЕ делает исключений из Wordfence по IP или User-Agent.
- Wordfence WAF в расширенном режиме может блокировать запросы ещё до запуска WordPress и данного плагина.
- Robots.txt не отменяет ограничения Nginx, CDN и WAF, не является гарантией краулинга.
- Физический robots.txt не редактируется: для него нужна ручная настройка.
- Успешный loopback-тест с собственного сервера не является проверкой доступности для AI-ботов из интернета.
- Google-Extended является управляющим токеном, а не отдельным HTTP User-Agent. GPTBot и ClaudeBot предназначены для обучения; по умолчанию правила для них не добавляются.
- Claude проверяется по официальному https://claude.com/crawling/bots.json; Grok не подтверждается без официального IP-источника.
- IP-сопоставление не является доказательством подлинности отдельного HTTP запроса.
- Для отчёта используется чтение внутренней таблицы Wordfence wfHits (до 5000 последних строк). Счётчики — только для найденных запросов, а не полный трафик за 7/30 дней. Исторические IP-диапазоны могут отличаться от текущих. Блокировки до PHP могут не фиксироваться.
- Режим All Traffic увеличивает объём журнала и нагрузку. Исторические события, которые не логировались раньше, не восстанавливаются.
